# v0.12.28.13 Security Hardening Plan

Base: 9dd4dbd49c5c2ce9c005c12afc24a86f8f593449
Scope: production security hardening; patch release v0.12.28.13 without changing score data Schema 1.

## S0 — Persisted-input XSS
- Escape every persisted/user-controlled value at HTML sinks.
- Add regression coverage for coordinate-insight exam names.
- Do not rely on CSP as the primary XSS control.

## S1 — One-time credential concurrency
- Introduce SQLite-backed Durable Object OneTimeCredentialGate.
- Serialize invitation, recovery-code, and recovery-link claims.
- Keep Workers KV as the business-data store.
- Release claims on failed writes; successful underlying state changes remain authoritative.

## S2 — Session revocation
- Add random session jti and short-lived server-side session record.
- Normal logout revokes only the current session.
- Password change / logout-all / recovery continue to invalidate by sessionVersion.

## S3 — Secret Share token transport
- New links use /share/#<token>.
- Browser removes fragment before redeeming.
- Redeem raw token through same-origin POST.
- Preserve legacy /api/share/secret/<token> compatibility.

## S4 — Bootstrap and abuse controls
- Disable ADMIN bootstrap in production by default.
- Permit a temporarily enabled bootstrap only once, then persist bootstrap:completed.
- Rate-limit share creation, revoke, public redemption.
- Return Retry-After on 429.

## S5 — Observability privacy
- Disable default Workers invocation logs so new Secret Share tokens are not placed in default request URL logs.

## Verification gate
1. Static source-contract checks.
2. CI verify + browser share tests.
3. PR ready only after green CI.
4. Merge only against exact tested PR head.
5. Verify main merge SHA.
6. Verify Cloudflare production version/build SHA with /api/health.
