## Product decision
1. **总成绩** is the current exam first, followed by a compact **历次总成绩** list when multiple exams are shared. A user should not have to enter 时间轴 merely to know what earlier total-score records exist.
2. **时间轴** remains the complete per-exam record. Each exam row may show only facts belonging to that exam: its own total score, school rank, and class rank. Never inherit the latest exam's rank into an older exam.
3. **单科** defaults to the latest exam that actually contains that subject, not merely the latest exam overall. In the primary subject fact, show the score first when the score is shared; ranks remain secondary in the historical rows. If score is not shared, fall back to the first available shared rank.
4. Share-field boundaries remain strict. Historical UI must never expose overall score/rank when those fields are not enabled.

## Acceptance criteria
- A two-exam share has: current total + historical total list + full timeline.
- Historical rows preserve each exam's own score/rank; no value is copied from another exam.
- A subject missing from the latest overall exam still opens at its latest actual subject record.
- A subject with a shared score shows the score as the primary current fact.
- No share-field regression or private-data leakage.
