## Goal
Reduce public-share cold-read fan-out, especially trajectory shares, without changing Schema 1, Share v2, permissions, share-field allow-list, comparison semantics, URL state, deleted-exam behavior, or visual design.

## P0 changes
1. Add repository-level KV bulk JSON reads, up to Cloudflare's 100-key binding bulk-read batch size.
2. Remove share-path listing of exam-summary:*; use the canonical exam-index:* already maintained by exam writes.
3. For single shares with an examId, read only the requested exam.
4. For trajectory shares, derive exam keys from the canonical index and bulk-read full exams in batches.
5. For single shares without an examId, resolve the latest exam id from exam-index and read only that exam.
6. Keep a bounded fallback for local/legacy KV test doubles that do not implement bulk reads; production Cloudflare KV must use bulk reads.
