# v0.15.2.0 — 私有端人类任务流收口

## 本轮目标

不改 Share v2、KV Schema 1 或家庭角色模型，修正私有站点最容易违背普通使用习惯的几个行为：

1. 考试列表先查看、再明确进入编辑。
2. 多孩子切换必须在新孩子数据读取成功后才提交状态。
3. 私有导航保留考试详情深链接。
4. 读取失败与“没有数据”严格区分。
5. 缺考可以没有 subjectSet。
6. 新考试默认日期使用本地日期。
7. 登录失败保留账号输入。

## 验收

- npm run verify
- Chromium 私有流程：考试查看/编辑、孩子切换失败、缺考保存、登录错误保留账号
- WebKit 390 回归
- exact PR HEAD
- merge 后 main SHA 与 production attestation
