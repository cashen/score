# Product Language Guide v0.12.22

## Write from observation
Prefer concrete facts: 英语 103 分; 校内第 2 名; 班级第 1 名; 9 月 16 日 · 月考.
Avoid describing how software thinks: 根据当前数据分析、变化来源、可比记录、口径一致、变化结论.

## Do not manufacture conclusions
State the boundary once and move on.
Preferred: 暂时没有可以直接比较的考试。之前有 1 场考试，但考试类型不同。
Not preferred: 还没有足够的相近考试数据来说明变化来源。

## Empty-state pattern
Use: what happened -> what is missing -> what the user can do.
Example: 这次只记录了英语。还缺语文、数学、物理、化学、生物。 Then offer 继续补充这次考试.

## Section naming
Prefer: 这次考试、这次成绩、和以前相比、历次考试、六科历史、继续补充这次考试、查看历次成绩.
Avoid: 具体坐标、整体位置、多次考试怎么看、变化来源、长期变化、趋势判断、可比记录.

## Repetition
Explain one fact once per visible page state. If a page already says 暂时没有可以直接比较的考试, do not repeat the same sentence in another card.

## AI-smell rule
Remove self-narrating phrases such as 先看再决定、现在还无法、从数据来看、值得回看、帮助你理解、进一步分析, unless immediately followed by a concrete user-visible fact.
