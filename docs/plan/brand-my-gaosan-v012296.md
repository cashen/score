# v0.12.29.6 品牌更名：我的高三

## 目标

将当前产品品牌从“高三坐标”更名为“我的高三”，让第一次接触产品的学生和家长能够直接把产品理解为“记录自己的高三”，而不是需要解释“坐标”是什么意思。

本次只做品牌文字层变更，不改变成绩事实、比较算法、认证、分享、KV、Schema 1、URL/API 或 Logo 图形语义。

## 品牌契约

- 产品名：我的高三
- 技术包名：score-track，保持不变
- 既有考试“轨迹”作为功能概念继续保留，不等同于产品名
- 现有副标题“看见这次成绩，也看见前后的变化”保持不变
- Logo B 图形保持不变

## 当前运行面

必须更新：

- `public/index.html` 浏览器标题
- `public/app.js` 产品名和面向用户的品牌文案
- `public/onboarding-v050.js` 产品名和面向用户的品牌文案
- `README.md` 当前产品标题与当前品牌描述
- `docs/ARCHITECTURE.md` 当前架构标题
- 品牌回归测试，使测试锁定“我的高三”

历史发布记录、历史 PR 描述和已完成 checkpoint 保留原品牌名称，不改写历史事实。

## 验收

1. 当前运行页面不再显示“高三坐标”作为产品名。
2. 登录、恢复、家庭建立等品牌入口统一显示“我的高三”。
3. README 与架构标题使用“我的高三”。
4. 品牌回归测试通过，确保 index/app/onboarding 的品牌契约不会回退。
5. `npm run verify` 全部通过。
6. PR 精确 head 与最终验证一致后才合并。
7. 合并后复核 main SHA、版本契约；生产仅在有可观察的部署/health attestation 时才记为已验证。
