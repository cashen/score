# v0.9.1 高三坐标 Logo B（成绩记录册）落地计划

## 用户场景与品牌目标

“高三坐标”是记录高三阶段考试成绩的工具，不是地图或排行榜。Logo B 的核心图形为一页成绩记录册/打开的记录页，内部以三次考试节点和轻微前行轨迹表达：青春的张力、持续投入的汗水、可核对的考试成绩、以及把每次记录放回时间里回看的过程。

Logo 不强制包含“标”字。图形需要在网站页眉、登录/引导页、分享页页眉、移动端和 favicon 尺寸下独立成立；文字标使用“高三坐标”，副标题继续使用“看见现在的位置，也看见一路的变化”。视觉保持克制、人本、低饱和：炭灰/暖灰为基础，弱蓝绿色仅作当前节点提示，不使用红绿排名语义、奖杯、箭头、地图针或游戏化徽章。

## 数据/API 影响

不改变 KV、认证、分享白名单、比较算法、API、Schema 或数据模型。只增加一个内联 SVG 标记组件与 scoped CSS，静态首页增加同源 Logo 样式资源；健康检查版本随补丁版本同步为 0.9.1，Schema 继续为 1。

## 分阶段任务与验收

### S0：实时接管、分支、计划与 PR

读取最新 checkpoint、main SHA、开放 PR、Actions 和生产健康；从精确 main 创建 `feat/logo-b-score-record`；把本计划和 checkpoint 提交并创建 PR。

验收：分支父提交等于实时 main；PR 目标为 main；计划完整写入 PR 描述。

### S1：Logo B SVG 组件

1. 新增 `public/brand-logo-b.js`，导出不依赖 DOM 的 `brandMark()`，输出安全的内联 SVG。
2. SVG 由记录页/书页轮廓、三条轻量记录线、三个考试节点与一条克制轨迹组成；最后节点使用弱蓝绿色，其他线条使用炭灰。
3. 组件不写入示例分数、不包含“标”字、不使用外部字体/图片/渐变/阴影。
4. 为图形提供 `aria-hidden` 装饰语义，产品名称和标题仍由相邻文本承担。

验收：SVG 在 16px favicon、34px 页眉、46px 登录标记下仍能辨认“记录页 + 节点”；SVG 字符串无用户输入，代码可通过 `node --check`。

### S2：全站入口接入

1. 更新 `index.html` 加载 Logo 样式，并替换 loading 标记。
2. 更新 `public/app.js` 的登录、顶部导航、空状态、恢复页、分享页标记；保持 `PRODUCT_NAME`、副标题、导航和分享语义不变。
3. 更新 `public/onboarding-v050.js` 的邀请/恢复引导标记；不恢复旧的 DOM 改写链。
4. 保留 `.brand-mark` 兼容类名，新增 `.brand-mark-score` 作用域，避免破坏现有布局。

验收：未登录、首次登录、家庭首页、空考试、分享页和恢复流程均使用同一 Logo；页面仍只有一个主应用入口；旧分享 URL 和 API 行为不变。

### S3：视觉与可访问性

1. 使用暖白/浅灰纸面、炭灰线条和单一弱蓝绿色节点；Logo 不表达“高分/低分”或成功/失败。
2. 检查深浅背景、窄屏、200% 缩放、键盘焦点、`prefers-contrast` 和 `prefers-reduced-motion`；Logo 不依赖动画或颜色才能理解。
3. 检查触控目标不因 Logo 接入而缩小；页眉标记保持现有最小尺寸。

验收：Chromium/WebKit 分享场景、登录/引导页面无溢出、无资源 404、无无障碍名称冲突。

### S4：测试、版本与文档

1. 增加 Logo SVG/CSS/资源契约测试，确保不再渲染“标”占位字，且所有主要入口引用组件。
2. 更新现有版本契约到 0.9.1，修改 `package.json`、lock、`wrangler.toml`、CHANGELOG 和相关测试；Schema 继续为 1。
3. 执行 `npm ci`、`npm run verify`；运行 Chromium/WebKit 浏览器回归和生产资源递归校验。

验收：本地单元/API/KV/白名单/比较/草稿/撤销与 Logo 测试全绿；浏览器多视口通过；生产构建资源完整。

### S5：精确合并与生产验证

PR head 与 GitHub 实际 `expected_head_sha` 一致、PR CI 全绿后合并。重新读取 main SHA，等待 main CI 与部署成功；生产 `/api/health` 必须返回 `appVersion: "0.9.1"`、`buildSha` 等于合并 SHA、`schemaVersion: 1`、`storage: "workers-kv"`；检查首页静态资源和 Logo SVG/CSS 引用。最后更新 checkpoint；任何网络超时均标记为未验证。

## 风险与回滚

Logo 为表现层改动，不涉及数据迁移。若视觉不符合预期，可回退 Logo 组件、样式和入口标记，恢复 v0.9.0 文件树；保留合并历史，不强制改写 main。风险主要是旧 CSS 覆盖、新 SVG 在窄屏溢出或旧测试仍期待占位字，分别通过新作用域、视口测试和契约更新规避。
