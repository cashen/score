# v0.8.0 成绩事实—对比—分享时间轴一体化计划

## 目标

把一次考试记录作为唯一事实源，并提供三种连续阅读方式：

1. 总成绩：看当前总分、总体位置和可比变化；
2. 单科对比：选择语文、数学、英语、物理、化学或生物，分别查看分数、校排、班排；
3. 时间轴：打开任意一场考试，查看全部允许展示的字段。

本版本解决“记录了数据却无法连续核对、比较口径不一致、分享时间轴只能看摘要”的问题。它不做高考预测、录取概率、能力判断、排行榜或游戏化激励。

## 产品原则

- 一场考试是一份完整事实；总成绩、单科和时间轴只是三种阅读视图。
- 只有口径明确且一致时才给出变化结论；数据不足时显示原因，不猜测。
- 分数、排名、百分位是不同指标，不能混成一个无单位的“进步值”。
- 只有一场考试时展示基线，不制造趋势。
- 分享“全部”指全部允许分享的字段，不包括家庭备注、账号、成员和安全信息。
- 保留 v0.7.0 的 Apple Design 克制、减少动效/透明度/高对比度支持、44px 触控目标和原生返回路径。
- 优先复用现有考试、KV、认证、revision、分享白名单和快照/持续更新合同。

## 范围与非范围

### 范围

- 统一比较状态和比较原因；
- 总成绩视图；
- 单科对比视图；
- 全量考试时间轴和单场详情；
- 分享页的总成绩/单科/时间轴阅读；
- 一场考试、两场可比考试、不可比考试和缺失数据状态；
- 版本、文档、checkpoint、单元/API/UI/生产回归测试。

### 非范围

- 不改变认证、家庭角色、KV key、删除恢复和 revision 机制；
- 不新增预测、AI 建议、录取结论、学生排名或社交；
- 不把家庭备注加入分享投影；
- 不强制新增持久化比较结果；
- 默认不升级 schemaVersion；若实现确需升级，必须先增加向后兼容读取和迁移测试。

## 分阶段任务

### S0 — 基线与恢复

- 从实时最新 main 创建分支 feat/score-v080-score-comparison-timeline。
- 读取最新 checkpoint、开放 PR、Actions、生产健康和资源版本。
- 将本计划写入仓库，并建立 .codex/progress/score-v080-score-comparison-timeline.json。
- 验收：分支基于最新 main；旧 v0.7.0 已完成事项不重复实现；工作区未提交修改不被覆盖。

### S1 — 比较事实合同

- 在单一模块中实现比较类别、系列、范围、排名 basis 和可比状态。
- 修复当前“记录被选入比较但提示又说不可比”的矛盾。
- 派生结果包含 baseline、comparable、not_comparable、insufficient_data、比较对象、原因和独立指标。
- 总分优先使用官方总分；不能把六科合计伪装成官方总分。
- 验收：单元测试覆盖一场、同类、不同类、不同系列、不同范围、缺排名、缺人数、不同计分模式和不同满分。

### S2 — 总成绩视图

- 在“轨迹”页增加 总成绩 / 单科对比 / 时间轴 平行切换。
- 总成绩首屏显示学生、最近考试、总分、校排、班排、百分位和比较口径。
- 一场考试显示“当前基线”；两场可比考试显示比较对象和方向；不可比时显示具体原因。
- 分数、校排、班排、百分位独立呈现。
- 验收：不产生虚假趋势；总分和排名不互相替代；360px、Pad、桌面均可读。

### S3 — 单科对比视图

- 增加六科选择器和 分数 / 学校排名 / 班级排名 指标切换。
- 历史记录按考试逐行展示；默认不使用复杂图表压过原始事实。
- 不同口径、计分模式、满分或排名 basis 不直接连线。
- 单科缺失时说明缺失字段；一场考试时只显示基线。
- 验收：六科切换不丢上下文；单位清楚；键盘可操作；所有触控目标至少 44px。

### S4 — 全量时间轴与单场详情

- 时间轴展示所有未删除考试，不再把最近 8 场作为永久上限。
- 每条记录使用原生链接/明确按钮打开单场详情。
- 详情展示考试上下文、官方/已计算总分的区分、总体排名、六科分数/模式/满分/排名和可比说明。
- 支持 exam、view、subject 查询状态，浏览器返回、刷新和复制链接不丢上下文。
- 验收：任意考试可打开；删除考试不出现；移动端无横向滚动；弱网不会因 JS 拦截导致链接失效。

### S5 — 分享阅读一体化

- 轨迹分享页提供 总成绩 / 单科 / 时间轴 三个阅读视图。
- 轨迹分享的时间轴覆盖全部允许分享的考试；任意考试可进入完整分享详情。
- 单场分享只展示指定考试。
- 快照和持续更新语义不变；撤销立即阻断详情。
- 白名单新增字段默认关闭；家庭备注、账号、家庭成员、恢复码和安全信息永不返回。
- 验收：私密链接、公开链接、单场、轨迹、快照、持续更新、撤销、详情深链接和白名单全部通过。

### S6 — 视觉、可访问性和弱网

- 保留 v0.7.0 的视觉基础，避免新增毛玻璃、过度徽章和页面级动效。
- 比较状态使用中性、可理解的文案；不可比不是错误警报。
- 支持 prefers-reduced-motion、prefers-reduced-transparency、prefers-contrast、键盘焦点和增大字体。
- 首屏不因时间轴或单科切换出现明显布局跳动。
- 验收：360px Android、Pad、桌面、键盘、慢网络和刷新/返回场景通过。

### S7 — 全量验证、PR、合并和生产

- 版本统一升级到 0.8.0：package.json、lockfile、wrangler.toml、健康检查和相关文档。
- 每阶段独立 commit；每阶段测试通过后更新 checkpoint。
- 执行 npm ci 和 npm run verify。
- 推送分支并创建 PR，PR 描述同步本计划、阶段状态、commit 和测试证据。
- 只在最终 PR head 的 exact-SHA CI 通过后，以 expected_head_sha 合并。
- 合并后重新核验 main SHA、main CI、Cloudflare 部署、/api/health 的 appVersion=0.8.0 与 buildSha、首页资源引用和运行时模块图。
- 验收：生产事实与最终合并 SHA 完全一致；checkpoint 标记完成。

## 数据/API 影响

- 优先只增加运行时派生比较对象，不写入比较结果。
- 复用现有考试字段、scope、fields、examId、快照/持续更新和白名单投影。
- 如需单场分享详情，优先通过现有投影数据加查询参数实现，不改变旧链接。
- notes 永远不进入外部 projection。
- 目标保持 schemaVersion=1；任何升级都必须先提供兼容读取和迁移回滚方案。

## 风险与回滚

- 比较规则变严：显示原因和原始记录，不删除数据。
- 时间轴变长：可渐进加载，但必须提供全部记录入口。
- 分享字段误扩散：服务端 allow-list 和投影回归测试双重拦截。
- 旧链接兼容问题：保留旧路由和旧字段读取。
- 生产回归：因不改 KV key 和默认 Schema，可回滚应用合并提交；不得删除用户数据。

## 完成定义

学生可以在只有一场考试时查看完整基线；录入第二场后分别比较总成绩和任意单科；打开时间轴任意考试查看全部允许字段；分享者可以在轨迹链接内切换总成绩、单科和时间轴；所有不可比、缺失和隐私边界都被明确说明。
