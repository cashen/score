# v0.8.1 分享页钢笔线描编辑风格计划

## 目标

把外部分享页重构成一份安静、可信、便于反复查看的“成绩手记”。视觉采用 XXD Panel 092 的钢笔语言：准确轮廓、方向排线、黑白疏密、自然留白和克制的编辑排版。成绩事实始终比装饰更醒目。

本次只处理家庭主动生成后的外部阅读页：

- 私密分享：`/share/:token`
- 公开分享：`/p/:slug`
- 总成绩、单科、时间轴和单场考试详情

家庭内的分享创建页、成绩录入、账户、家庭成员和其他页面不进入本次视觉重构。

## 用户场景与人本目标

### 只有一次成绩

学生或家长打开分享链接时，首先看到这次考试的真实信息，并明确知道它是“当前基线”。总成绩、六科和时间轴三个入口都可以使用，但页面不生成趋势、不暗示进步或退步。

人本目标：

- 一次成绩也值得完整呈现；
- 让查看者理解“还没有形成趋势”，而不是误以为功能缺失；
- 下一次录入后自然扩展为多次记录，不改变阅读方法。

### 已有多次成绩

查看者可以在总成绩、单科和时间轴之间切换，打开任意一次考试核对允许分享的字段。页面保留原有比较边界，不把考试难度或口径差异解释为能力变化。

### 手机中查看

分享通常从微信等聊天工具打开。页面必须在 360px 宽度下直接可读，入口可以触摸，返回和刷新保留当前视图，不依赖横向拖动才能看见关键数据。

### 隐私判断

查看者始终看得见“由家庭主动分享、可以撤销、请勿转发”的来源说明。钢笔画风格不能削弱隐私边界或制造类似证书的权威感。

## 视觉转换原则

XXD Panel 092 原始风格用于网页时对应以下规则：

| 钢笔语言 | 网页表达 |
| --- | --- |
| 松散而准确的轮廓 | 细墨色边线、清晰分区、轻微不对称的编辑节奏 |
| 方向排线与交叉排线 | 只用于页眉、当前标签和分区端点的小面积纹理 |
| 大面积负空间 | 增加段落呼吸和页面留白，减少连续卡片盒子 |
| 黑、灰、纸白 | 暖纸白背景、深墨正文、低饱和蓝灰辅助色 |
| 选择性细化 | 总成绩和当前考试最清晰，说明与历史信息逐级变轻 |
| 手工痕迹 | 使用细线、虚实变化和微小错位，不使用难读的仿手写中文字体 |

约束：

- 不把整页做成背景图片，也不引入大体积纹理资源；
- 不使用粗黑漫画线、卡通图标、灰脏滤镜或模板海报；
- 排线只负责识别结构，不覆盖数字、文字或操作区域；
- 保留 Apple 风格的清晰层级、可访问性和触控尺寸。

## 信息结构

### 分享页页首

依次展示：

1. 高三坐标分享标识；
2. 家庭主动分享与禁止随意转发提示；
3. 总成绩 / 单科 / 时间轴三个阅读入口；
4. 当前视图的事实内容。

三个入口使用类似速写本索引的线性导航。当前入口由墨线与小面积排线共同标识，同时保留文字和 `aria-current`，不依赖颜色判断。

### 总成绩

- 学生身份和当前考试构成首要视觉锚点；
- 总分、校排名、班排名保持同一坐标关系；
- 六科按行呈现；
- 只有一次记录时显示“当前基线”及解释；
- 分享模式继续显示“只分享当前内容”或“持续更新”。

### 单科

- 六科切换保持 44px 触控区域；
- 每场考试仍按事实逐行展示；
- 只有一次记录时说明“目前只有一次记录，先看这一场的事实”；
- 缺失分数或排名继续明确显示“数据待补”。

### 时间轴和考试详情

- 一次成绩也形成一个明确时间节点；
- 时间节点使用原生链接，可刷新、复制和返回；
- 打开后显示总成绩、总体排名和六科公开详情；
- 时间轴末尾继续说明只展示分享白名单字段。

## 数据、API 与安全影响

- 不修改 KV key、认证、角色、revision、删除恢复和分享撤销；
- 不修改分享 API 路由、快照/持续更新语义和公开 locator；
- 不扩大服务端分享白名单，不加入 notes、账号、家庭成员或安全信息；
- 保持 `schemaVersion=1`；
- 页面继续消费 v0.8.0 已提供的公开投影。

实现预计只涉及分享页渲染语义、新增一层作用域明确的 CSS、入口资源、版本号、测试和文档。

## 分阶段任务

### S0 — 基线、计划与恢复点

- 从实时最新 `main` 创建 `feat/score-v081-share-ink-editorial`；
- 核验开放 PR、Actions、生产健康和资源；
- 记录 v0.8.0 checkpoint 与 GitHub 事实的差异；
- 写入本计划和新 checkpoint。

验收：

- 分支基于 `659344d5aa914fcf14d9bfeca9567ea7ae4ee518` 或执行时更新后的最新 main；
- 不覆盖旧工作区修改；
- v0.8.0 的总成绩、单科和时间轴能力不被重复开发。

### S1 — 单次成绩的分享语义

- 为分享页增加记录数量与基线说明；
- 总成绩、单科和时间轴分别给出与当前视图匹配的单次状态；
- 多次成绩不显示单次基线文案；
- 保留原生查询参数与深链接。

验收：

- 一次成绩下三个入口均可理解；
- 页面不出现趋势、改善或退步判断；
- 零记录、多记录和字段缺失状态仍成立。

### S2 — 钢笔线描视觉层

- 新增只作用于 `.public-shell` 的 v0.8.1 分享页样式；
- 使用暖纸白、深墨线、留白、细分隔线和小面积排线；
- 重构页首、隐私提示、导航、总成绩、单科行、时间轴和详情；
- 私有应用界面不受影响。

验收：

- 360px、Pad 和桌面布局均无关键内容横向溢出；
- 排线不遮挡数据；
- 视图之间保持一致的视觉语言；
- CSS 不引入外部字体、背景大图或页面级动画。

### S3 — 可访问性、版本与回归

- 保持键盘焦点、`aria-current`、语义链接和至少 44px 触控区域；
- 支持减少动效、减少透明度和高对比度；
- 版本同步升级为 `0.8.1`；
- 新增分享页语义、样式作用域和资源顺序测试；
- 执行 `npm ci` 与 `npm run verify`。

验收：

- 全量测试通过；
- KV、认证、分享白名单、草稿、恢复、比较口径和 Schema 回归通过；
- 版本来源与健康检查一致。

### S4 — PR、合并与生产验收

- PR 描述同步本计划和阶段状态；
- 最终 PR head 的 CI 通过后，用 GitHub 实际 head 作为 `expected_head_sha` 合并；
- 核验 main CI、Cloudflare 部署、生产健康检查和资源引用；
- 生产分享页资源包含 v0.8.1 样式；
- 更新 checkpoint 为完成。

验收：

- `/api/health` 返回 `appVersion=0.8.1`，`buildSha` 等于本次 main 合并 SHA；
- 生产首页按顺序加载 v0.8.1 分享样式；
- PR、CI、部署和生产事实均可追溯。

## 测试方案

### 源码与单元测试

- 三个分享入口继续存在；
- 单次成绩基线文案仅在 `exams.length === 1` 时出现；
- 分享详情继续只使用公开投影；
- 新 CSS 所有视觉规则均限定在分享页作用域；
- 当前标签不能只依赖颜色，触控区域不少于 44px；
- 减少动效、减少透明度和高对比度媒体查询存在。

### API 与集成回归

- 单场/轨迹、私密/公开、快照/持续更新；
- 分享撤销；
- notes 与家庭安全信息不进入投影；
- KV 创建、读取、更新；
- CSRF、家庭角色、删除恢复和 revision。

### 生产检查

- 健康检查的版本、构建 SHA、Schema 和存储类型；
- 首页资源引用顺序；
- `/share/*` 与 `/p/*` 仍走现有路由；
- 静态 CSS 可访问且来自本次部署。
- 部署工作流执行 `node scripts/verify-production.mjs "$TESTED_SHA"`：校验完整健康契约、首页与两个分享入口 HTML；递归追踪首页 CSS、入口脚本及动态 / 静态模块导入，逐项比对生产响应和已测试提交的 SHA-256。
- 验证器自身覆盖成功、健康 SHA 不符、健康正常但资源过期三个回归场景。任何不符都使部署验收失败。

## 风险与回滚

### 浏览器验收补充（2026-09-09）

当前交互浏览器不能访问本地预览。通过项目 CI 内独立的 `share-browser` job 执行可复现验收，不发布临时公网预览，不调用生产写接口。

- 固定开发工具版本 `@playwright/test@1.63.0`（已核对 npm registry），不加入生产依赖；参考 [Playwright 官方 CI 指南](https://playwright.dev/docs/ci)。
- `browser-tests/server.mjs` 仅提供仓库静态资源；分享 API 使用通过真实 `publicProjection` 生成的虚构数据。
- Chromium 覆盖 360 / 390 / 768 / 1280px，WebKit 覆盖 390px。
- 验收总成绩、全部六科切换、单场 / 多场时间轴、详情、刷新返回、空数据、白名单缺省、快照文案、键盘焦点、减少动效与高对比度。
- 检查实际页面横向溢出与可点击区域尺寸；保存截图、失败追踪与 HTML 报告，供视觉复核。
- 减少透明度继续由现有源码回归约束；不把未模拟的偏好称为浏览器已验收。
- 本地复现：`npm ci`、`npm install --no-save --package-lock=false @playwright/test@1.63.0`、`npx playwright install --with-deps chromium webkit`、`npx playwright test`。
- `verify` 与 `share-browser` 两个 job 均成功才允许合并；main 的完整 CI 成功后原有部署 workflow 才能运行。
- 若 CI 工具安装或浏览器执行失败，记录实际原因，保持 PR 未合并，不降级为源码断言通过。

- **风格压过信息**：限制排线面积，数字区域保持纯纸白；可通过移除 v0.8.1 CSS 引用回滚。
- **分享页选择器污染私有页面**：所有新增规则以 `.public-shell.ink-share` 开头，并用测试约束。
- **单次状态误导**：文案只陈述记录数量和当前基线，不推断趋势。
- **旧链接回归**：不改变路由和查询参数；旧分享地址直接使用新阅读层。
- **生产异常**：本次不迁移数据，应用提交可回滚，不需要修改用户 KV。

## 完成定义

分享链接在只有一次成绩时也完整呈现总成绩、单科和时间轴，并明确说明当前只是基线；多次成绩继续使用原有事实与比较边界。页面呈现可辨认的钢笔线描编辑气质，同时保持隐私、可访问性、移动端阅读和加载性能。
