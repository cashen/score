# v0.9.2 分享链接与分享图交付计划

## 目标与用户场景

当前分享管理页在“已经创建的外部地址”中只显示 `/p/<slug>` 路径片段，普通学生或家长仍需理解域名和路径拼接才能分享；创建时的复制动作也没有在列表中留下可再次操作的入口。本版本把“创建后交付给别人”作为完整任务：用户能看懂地址、复制地址、打开分享页，并把当前允许分享的总成绩、单科和时间轴生成图片，适配电脑、手机和受限内置浏览器。

## 人本与安全目标

- 公开链接显示完整绝对地址（使用当前 `location.origin`），地址可选择、可长按复制。
- 复制是每条公开链接的第一主操作；打开和下载分享图是次操作；撤销保持危险操作但不抢主视觉。
- 随机 secret token 仍不在刷新后的列表中回显。创建成功时提供复制、打开和下载分享图；已存在 secret 使用登录态预览接口生成图片，不返回 token。
- 图片只使用分享白名单投影，不包含备注、账号、家庭成员、恢复码或未分享字段；明确显示快照/持续更新和当前基线边界。
- Clipboard、Web Share、下载能力都不是唯一成功路径；失败时提供可选择的完整 URL、图片预览和“长按保存”提示。

## 数据/API/UI 影响

### 数据与 API

不修改 KV Schema（继续为 1），不修改公开分享 URL 语义。新增一个需要登录的分享预览读取接口：

`GET /api/students/:studentId/shares/:kind/:locator/preview`

接口验证当前成员、学生归属、分享索引归属、撤销/过期状态，并复用既有 snapshot/live、single/trajectory 和 `publicProjection` 白名单逻辑。响应只含用于分享图和预览的 `share` 元数据与 `data` 投影，不含 secret 原文 token。

### 前端

- `renderShareList()` 为公开链接生成完整 URL，并渲染复制、打开、下载分享图动作；secret 行保留安全说明，并提供登录态预览下载。
- 创建结果保存短生命周期的内存状态，在成功提示区域显示完整动作，不把 secret token 写入 localStorage 或服务端索引。
- 新增分享图模块，使用原生 Canvas/SVG 绘制，不引入外部截图依赖；默认生成适合移动端转发的竖版 PNG，时间轴过长时自适应高度或分页。
- 分享页增加“保存分享图/系统分享”入口，当前总成绩、单科或时间轴视图与图片内容一致。

## 分阶段任务与验收标准

### S0：实时接管、计划与 PR

读取 checkpoint、main SHA、开放 PR、Actions、生产健康和首页资源；从精确 main 创建 `feat/share-link-copy-image-v092`；提交本文档和 checkpoint；创建 PR 并把同一计划写入 PR 描述。

验收：分支父提交等于实时 main `979e02a…`；无开放冲突；计划和恢复规则可在断网后继续执行。

### S1：完整地址与复制/打开

抽取安全的 `shareUrlFor(item)`；公开链接渲染绝对地址、只读可选择容器、复制按钮和打开按钮；复用 `copyText()`，增加复制成功/失败状态和 `aria-live` 提示。保留撤销确认，不把 secret token 写进分享列表。

验收：无需手动拼接 `/p/`；公开链接可在同一页面再次复制；URL 长度在 320px 和 200% 缩放下不横向溢出；撤销、过期和原有分享范围不变。

### S2：安全分享预览

新增登录态预览路由，验证家庭成员隔离和分享索引；snapshot 读取存档投影，live 读取当前白名单投影；撤销/过期/不存在返回现有人类可读错误。前端将预览结果交给分享图模块，不暴露 secret 原文。

验收：secret/public、single/trajectory、snapshot/live 均与外部分享页口径一致；备注、账号和未勾选字段不可通过预览接口获得。

### S3：分享图生成、下载和系统分享

实现可测试的 Canvas/SVG 导出器，绘制身份、考试元信息、总成绩、单科表、时间轴和边界说明；支持当前分享视图与分享白名单。桌面端提供 PNG 下载；支持文件分享的移动端调用 `navigator.share`；受限浏览器回退为图片预览、下载链接和长按保存提示。生成过程有明确的进行中、成功和失败状态，文件名不包含敏感身份信息。

验收：图片内容不超出投影；无第三方资源/CORS 依赖；窄屏、长 URL、多考试时间轴和中文字体可读；下载被阻止时仍能保存图片。

### S4：分享页与多终端可访问性

分享页和分享管理页统一动作文案；移动端按钮最小触控高度 44px；键盘可达、Enter/Space 可操作、Escape 可关闭预览；支持 `prefers-reduced-motion`、`prefers-contrast`；不以颜色作为唯一含义，不增加游戏化徽章。

验收：Chromium/WebKit 在 320/375/768/1440px 视口、横竖屏、200% 缩放下无溢出、无 404；Alook/微信内置浏览器至少能复制文本或长按保存图片。

### S5：测试、版本与文档

新增 URL/复制状态、预览白名单/成员隔离、图片投影一致性、下载和降级契约测试；回归 KV、认证、分享白名单、比较、草稿、删除撤销和分享页面。执行 `npm ci`、`npm run verify`，更新 `package.json`、lock、`wrangler.toml`、健康检查和 CHANGELOG 至 `0.9.2`。

验收：单元/API/浏览器/生产资源测试全绿；Schema 仍为 1；生产构建递归资源检查包含新增模块。

### S6：精确合并与生产验证

确认 PR 实际 `head_sha` 后等待 PR CI 成功，以 `expected_head_sha` 合并；重新读取 main SHA，等待 main CI 与部署；生产 `/api/health` 必须返回 `appVersion: 0.9.2`、合并 SHA、`schemaVersion: 1`、`storage: workers-kv`。验证首页、分享页、复制地址、图片资源和撤销语义，最后更新 checkpoint。

## 风险、回滚与断网恢复

- secret 泄漏：列表不回显原 token，预览只返回白名单投影；若发现越权，立即关闭预览入口并回滚前端按钮。
- 图片在内置浏览器无法下载：保留文本 URL、图片预览和长按保存路径。
- Canvas 内存或长时间轴过大：限制单页尺寸并分页，不阻塞原分享页。
- 版本/边缘缓存不一致：以生产健康的版本和 build SHA 为准，未知网络结果不记为成功。
- 本版本无数据迁移；可通过回滚新增路由、导出模块、样式和入口，恢复 v0.9.1。
