# 我的高三 Exam Entry UI v0.14.2.0

## 目标
把新建/编辑考试界面从“配置面板”进一步变成“安静的成绩记录页”。

## 设计变化
- 信息分区保留“考试信息 → 总分与位置 → 单科成绩 → 备注”的顺序。
- 去掉科目卡片的厚重背景和圆角层级，用轻量分隔线建立阅读节奏。
- 成绩输入成为每科视觉重点；计分方式、满分、排名降为辅助信息。
- 班级/学校排名使用轻量行，不把缺失人数当成错误。
- 保存区保持单一主要操作，不改变删除、保存、草稿行为。
- 移动端维持单列，保持现有触控尺寸。

## 不变
- Schema 1、Workers KV、Share v2。
- Exam / Score / Comparison 语义。
- 现有 data-action / data-subject / form field names。
- 浏览器测试行为和 API contract。

## 验收
- npm run verify。
- Chromium 360 / 390 / 768 / 1280。
- WebKit 390。
- 单科、三科、六科录入及保存回归。
