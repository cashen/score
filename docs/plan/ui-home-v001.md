# 我的高三 Homepage & Navigation v0.14.1.0

## 目标

把首页从“成绩仪表盘”改成“家庭成绩记录首页”：先看到最近一次考试，再看到最近变化、这次科目，最后决定下一步。

## 本轮范围

- 首页信息层级重排。
- 缺失科目、六科总分未公布等状态改成中性、可继续处理的表达。
- 主导航与成绩子导航统一布局和触控节奏。
- 学生切换、账号菜单与隐私提示视觉弱化但不改变功能。
- 手机 / Pad / PC 保持相同信息层级。

## 不变

- 成绩事实、比较算法、考试生命周期。
- Schema 1、Workers KV、Share v2、家庭角色和 API。
- 既有 data-action / data-tab / URL 状态。

## 验收

- npm run verify。
- Chromium 360 / 390 / 768 / 1280。
- WebKit 390。
- 首页无考试、一场、多场考试。
- 单科、时间轴入口继续可导航。
