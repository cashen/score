# v0.7.0 高三坐标：Apple Design 人本 UI 执行计划

## 目标

在不改变 v0.6.0 数据和安全边界的前提下，把高三坐标首页及核心交互收敛为“先看懂、再行动、随时可恢复”的家庭工具。Apple Design 只作为人本交互与细节标准，不作为外观复制目标。

## PR 执行规则

1. 从远端最新 `main` 创建本分支；不覆盖用户未提交修改，不使用 `reset --hard` 或强制覆盖。
2. 每个阶段都有独立提交；阶段测试通过后才进入下一阶段。
3. 只把已提交代码和对应测试结果写成 completed；网络超时或工具无结果视为 unknown，重新核验后再操作。
4. PR 描述同步阶段状态、提交 SHA、测试命令和已知限制；断网恢复时先读本计划和 `.codex/progress/ui-v070-apple-human.json`，再核对 GitHub 实际状态。
5. 合并前必须满足：最终 PR head 的 `npm run verify` 通过、CI 对同一 SHA 成功、无未解决阻塞；使用 expected head SHA 合并。
6. 合并后必须重新核验 `main`、主分支 CI、Cloudflare 部署与 `/api/health` 的 `appVersion=0.7.0` 和 `buildSha`。

## 分阶段任务

### S0 — 基线、计划、断点

- 固定远端 main SHA、工作树状态、开放 PR、最近 Actions 和生产版本。
- 写入本审计、执行计划和断点文件。
- 验证：`git status`、计划文件存在、远端 main SHA 与记录一致。

### S1 — 视觉基础与隐私信号

- 新增 `public/ui-v070.css`，由 `index.html` 作为最后一个 UI 样式源加载。
- 采用系统字体、克制的中性色、单层材质和明确的焦点样式；不叠加玻璃层。
- 顶部增加安静的“仅家庭可见”状态，不改变权限逻辑。
- 移动端导航固定在安全区域内，所有触摸目标至少 44px；桌面保持现有四个业务入口。
- 验证：CSS 语法/选择器检查、移动布局契约测试、键盘焦点和 reduced-motion 契约测试。

### S2 — 首页“当前坐标 → 变化 → 行动”

- 保留现有坐标与可比算法，只调整阅读层级和文案容器。
- 有数据时增加唯一主动作“记录下一次考试”；保留“编辑这次考试”作为次级动作。
- 增加事实性摘要，明确比较对象和不可比状态；不做能力归因。
- 轨迹入口拥有稳定 ID 和明确按钮行为，点击后打开并滚动到完整轨迹。
- 无数据状态继续使用“记录第一次考试”，并保持查看权限提示。
- 验证：首页渲染契约、按钮事件契约、可比性回归测试、无数据/只读状态测试。

### S3 — 录入、反馈与可恢复交互

- 不改变现有三步表单字段和保存 API；统一按下反馈、禁用态、错误定位和成功提示。
- 保留本机草稿恢复；在视觉上区分“本机草稿”“已保存考试”“最近删除”。
- 对删除、撤销、关闭等可逆动作不增加多余确认；对不可逆的退出所有设备仍保留明确确认。
- 对话框、抽屉和详情过渡使用可中断的 CSS transition；`prefers-reduced-motion` 时只保留淡入淡出。
- 验证：表单回归、草稿回归、删除/恢复回归、错误/状态区域可访问性测试。

### S4 — 分享、轨迹和边界状态的人话审查

- 只调整分享页的视觉层级和状态呈现，不改白名单投影。
- 让“将分享 / 不会分享 / 默认家庭可见 / 可撤销”成为连续阅读，不制造隐私恐慌。
- 对没有第二次可比考试、缺失参与人数、缺失排名等情况显示具体解释。
- 验证：分享范围、撤销、快照/持续更新、不可比和空数据测试。

### S5 — 版本、全量验证、PR 与生产验收

- 版本统一升级到 `0.7.0`：`package.json`、`package-lock.json`、`wrangler.toml` 和相关契约测试。
- 执行 `npm run verify`，再推送分支并创建/更新 PR。
- 等待最终 exact-head CI；若失败只修复失败原因并重新验证，不重跑已证明无变化的步骤。
- 使用 expected head SHA 合并到 `main`。
- 合并后核验主分支 CI、部署 workflow、Worker `/api/health` 与线上页面资源版本。

## 完成定义

- 视觉方向与草图一致：清晰的当前状态、变化结论、单一主动作和轨迹入口。
- 不新增计划外业务，不改变后端合同，不泄露家庭备注或安全信息。
- 360px Android、桌面、键盘、增大字体、减少动态均通过验收。
- 仅在最终 head 的 CI 与生产版本核验均通过后宣布完成。
